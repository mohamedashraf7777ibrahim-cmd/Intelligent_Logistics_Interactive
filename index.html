THE RESEARCH LAYER

From routing problem to decision support

Core concepts behind an intelligent logistics routing prototype.

01 / PROBLEM

The logistics challenge

Delivery planning is a constrained decision problem. A route must connect a start to a destination while respecting available roads. Closures and delivery stops can change the best feasible plan.

02 / MODEL

Graph representation

Intersections become nodes and road connections become edges. Each edge has a cost. This prototype uses uniform edge costs so the assumptions remain easy to inspect.

03 / ALGORITHMS

Pathfinding methods

Dijkstra explores the lowest accumulated cost first. BFS explores by number of edges and finds a fewest-edge path in an unweighted graph. Equal edge costs can produce paths with equal length.

04 / RESILIENCE

Dynamic response

When a road closes, the graph changes. The simulator removes that connection and searches again. If no path remains, it reports that the destination is unreachable.

RESPONSIBLE INTERPRETATION

Limitations & next steps

Good engineering makes assumptions visible and identifies what a prototype does not solve yet.

Current limitations

  • Synthetic network, not a geographic map.
  • Time and cost are illustrative estimates.
  • No live traffic, GPS, weather, or fleet data.
  • Stops are visited in entered order, not globally optimized.

Future development

  • Import verified road-network and distance data.
  • Add weighted edges for time, distance, tolls, and restrictions.
  • Explore A* with a suitable geographic heuristic.
  • Extend toward vehicle routing with capacity and time windows.
